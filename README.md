## Convenções de Acesso e Licenciamento

| Rótulo | Definição |
| :--- | :--- |
| **Open Source** | Código aberto e gratuito sob licenças reconhecidas pela OSI (MIT, Apache 2.0, BSD, etc.). |
| **Gratuito** | Acesso integral sem custos diretos, mas o serviço/código pode ser proprietário. |
| **Freemium** | Recursos essenciais gratuitos com plano pago para escalabilidade ou funções avançadas. |
| **Comercial / Pago** | Produto essencialmente comercial com foco corporativo ou acesso limitado a testes. |

> **Aviso de Propriedade Intelectual:** A classificação "Gratuito" refere-se ao acesso à ferramenta. Ativos de design, ícones de marcas registradas e bibliotecas de terceiros possuem termos de uso individuais. Sempre valide as diretrizes de licenciamento antes de integrar ativos em projetos comerciais.

## Manutenção e Diretrizes de Contribuição

Para garantir a escalabilidade e a qualidade deste catálogo, siga estas diretrizes ao adicionar ou atualizar itens:

1. **Ordenação:** Mantenha as categorias organizadas pelo sumário. Dentro de cada categoria, adicione os recursos por ordem alfabética do nome.
2. **Formatação de Tags:** Use apenas minúsculas, separadas por hífen e sem acentuação (ex.: `#open-source`, `#design-system`).
3. **Validação de Modelo de Acesso:** Certifique-se de marcar com exatidão se o serviço é `Open Source`, `Gratuito`, `Freemium` ou `Comercial / Pago`.
4. **Propriedade e Licenças:** Sempre alerte se um ativo exigir atribuição autoral obrigatória ou envolver marcas registradas.
