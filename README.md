## 🏷️ Legenda de acesso
| Rótulo | Significado |
|---|---|
| Grátis / Open Source | Uso e código-fonte livres, geralmente sob licença OSI (MIT, Apache-2.0 etc.) |
| Grátis / catálogo | Site gratuito que agrega/indexa recursos de terceiros (as licenças de cada item variam) |
| Freemium | Camada gratuita real + funcionalidades pagas adicionais |
| Free + Pro / pago | Uso gratuito com limites, e um plano pago claramente separado para uso avançado/comercial |
| Pago / empresarial | Produto essencialmente comercial, com preços voltados a empresas |
| Não verificado | Não foi possível confirmar o modelo de acesso em fonte oficial no momento da checagem |

> **Nota sobre licenças:** "Grátis" descreve o *acesso ao site/ferramenta*, não a licença do conteúdo gerado ou dos ativos (fontes, ícones, paletas, componentes). Sempre confira a licença específica do item antes de redistribuir ou usar comercialmente — isso é sinalizado na coluna "Observação" quando relevante.

## 🔖 Como usar as tags

Cada recurso tem uma coluna **Tags** com palavras-chave em `minúsculas-com-hífen`, sem acentos, para facilitar a busca (Ctrl+F) no arquivo — por exemplo, procure por `#tailwind` para listar todos os itens ligados a Tailwind CSS. As tags seguem quatro famílias:

| Família | Exemplos | Para que serve |
|---|---|---|
| Tecnologia | `react`, `vue`, `svelte`, `tailwind`, `bootstrap`, `css`, `html`, `javascript`, `threejs`, `svg` | Stack ou linguagem com que o recurso trabalha |
| Tipo de recurso | `componentes`, `templates`, `icones`, `gerador`, `diretorio`, `cheatsheet`, `documentacao`, `validador`, `playground` | O que o recurso é |
| Tema / domínio | `acessibilidade`, `seguranca`, `performance`, `seo`, `osint`, `api`, `3d`, `tipografia`, `paletas`, `imagens` | Área de aplicação |
| Característica | `copiar-e-colar`, `headless`, `animacao`, `offline`, `dark-mode`, `google`, `comunidade` | Modo de uso ou traço marcante |

> As tags são classificações editoriais (não vêm de fonte oficial) e foram atribuídas a partir da descrição de cada entrada.
